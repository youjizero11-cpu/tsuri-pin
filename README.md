# 釣果ピン（tsuri-pin）

船釣り用の「釣果ピン記録」アプリです。釣れた場所にピンを打ち、次回そこへ戻れます。
スマホのホーム画面に追加して使うWebアプリ（PWA）で、電波の届かない海上でも動きます。

**現在は開発中です（段階5：ピンを打つ、釣果と写真の記録、一覧、ピンへ戻るナビまで。データの書き出しはこれから）。** 仕様は [SPEC.md](SPEC.md) を見てください。

## 特徴（予定を含む）
- ボタン1つで現在地と日時を保存
- 釣果（写真・魚種・サイズなど）をピンにひもづけて記録
- 保存したピンまでの距離と方角を表示
- データはすべて端末の中に保存。サーバーには送りません
- CSV / JSON での書き出し

## 使うときの注意
- 出港前に、電波のある場所で一度アプリを開いてください
- データは端末の中にしかありません。定期的に書き出して保管してください
- iPhone は Safari で開き、「ホーム画面に追加」して使ってください

## パソコンで動かす
このフォルダで次を実行し、ブラウザで `http://localhost:8000` を開きます。

```
python -m http.server 8000
```

## 技術
HTML / CSS / JavaScript のみ。ビルドツール・フレームワーク・外部ライブラリは使っていません。
