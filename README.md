# 釣果ピン（tsuri-pin）

船釣り用の「釣果ピン記録」アプリです。釣れた場所にピンを打ち、次回そこへ戻れます。
スマホのホーム画面に追加して使うWebアプリ（PWA）で、電波の届かない海上でも動きます。

- アプリを開く: https://youjizero11-cpu.github.io/tsuri-pin/
- 仕様: [SPEC.md](SPEC.md)

**状態:** 予定していた機能はすべて入っています。iPhone の屋内では確認済みです。屋外でのナビ、Android、海上での確認はこれからです。

## できること
- **ピンを打つ** — 大きなボタン1つで、現在地と日時を保存します
- **釣果を記録する** — 写真・魚種・サイズ・匹数・水深・タナ・仕掛け/エサ・メモ。先にピンだけ打って、あとから入力できます
- **同じ場所に釣果を足す** — 近くにピンがあれば、そこに追加するかを聞きます
- **ピンを探す** — 日付順の一覧と、魚種での絞り込み
- **地図で見る** — 日本地図の上にピンの場所を表示。印を押すと、その海域のピンの位置関係と、現在地からの距離が分かります（圏外でも動きます）
- **海の深さを見る** — ホーム画面のボタンから、HONDEX（本多電子）の「Web海図」をブラウザで開けます。リンクで開くだけで、海図のデータはアプリに取り込んでいません
- **行きたい場所を先に登録する** — 地図を動かすか、緯度・経度を入力して、行く前にピンを作れます。目で合わせるので数十〜数百mずれます（地図に海の深さは出ません）
- **ピンへ戻る** — ピンまでの距離と方角を、大きな数字と矢印で表示します
- **データを書き出す** — CSV（表計算用）とバックアップ（JSON）。バックアップは読み込んで元に戻せます

## はじめかた

### iPhone
1. **Safari** で上のURLを開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」
3. ホーム画面にできた「釣果ピン」のアイコンから開く
4. 位置情報を聞かれたら「アプリの使用中は許可」を選ぶ

### Android
1. **Chrome** で上のURLを開く
2. 右上のメニュー（︙）→「ホーム画面に追加」または「アプリをインストール」
3. ホーム画面にできた「釣果ピン」のアイコンから開く
4. 位置情報を聞かれたら「アプリの使用時のみ」を選ぶ（「正確な位置情報」はオンのまま）

## 海に出る前に
- **電波のある場所で、一度アプリを開いてください。** そのときにアプリ一式が端末に保存され、圏外でも開けるようになります。設定画面の「オフライン準備」が「完了」になっていれば大丈夫です
- **必ずホーム画面のアイコンから使ってください。** ブラウザで開いたままだと、長く使わなかったときにデータが消されることがあります
- **圏外では、最初の位置取得に時間がかかることがあります。** 30秒ほど待ってください

## 使うときの注意
- **データは端末の中にしかありません。** 端末の故障・紛失・機種変更で消えます。設定画面の「バックアップを書き出す」で、ときどき保管してください
- **書き出したファイルには釣り場の位置が入っています。** 渡す相手に気をつけてください
- **ナビの矢印は、スマホのコンパスを使います。** 船の金属やエンジンの近くでは狂うことがあります。そのときはナビ画面で「進行方向（GPS）基準」に切り替えてください
- **アプリの中の地図は、おおまかな輪郭です。** 数kmのずれがあり、小さな島は入っていません。岩や浅瀬を避ける目的には使えません
- **「地図で開く」「Googleマップで見る」は電波のある場所でだけ使えます。** 押したときだけ、その位置がGoogleマップに送られます

## データの扱い
- 記録（位置・釣果・写真）は、すべて端末の中に保存します。サーバーには送りません
- アクセス解析や広告は入れていません
- 「行きたい場所をピンにする」の地図を表示している間は、見ている範囲が国土地理院のサーバーに伝わります（地図の画像を取りに行くため）。ピンや釣果は送られません
- それ以外で外部へ情報が出るのは、自分で「地図で開く」「Googleマップで見る」を押したときと、自分でファイルを書き出して渡したときだけです

## パソコンで動かす（開発用）
このフォルダで次を実行し、ブラウザで `http://localhost:8000` を開きます。

```
python -m http.server 8000
```

- パソコン（localhost）では、直した内容がすぐ画面に出るよう、オフライン用の保存を止めてあります。オフライン動作を試すときだけ `http://localhost:8000/?sw=1` で開きます
- ファイルを変更して公開するときは、`sw.js` の `VERSION` を上げます。上げないと、使っている人の端末には古いファイルが残ります

## 技術
HTML / CSS / JavaScript のみ。ビルドツール・フレームワーク・外部ライブラリは使っていません。
データは IndexedDB、オフライン動作は Service Worker、公開は GitHub Pages です。
ファイルの構成と各ファイルの役割は [SPEC.md](SPEC.md) の「5. ファイル構成」にあります。

「行きたい場所をピンにする」の地図は、[国土地理院の地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)（標準地図）を表示しています。

日本の輪郭のデータは [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）から、日本の部分だけを取り出して使っています。
